# ☘️ Black Clover — Inscriptions Donjons

Site d'inscription pour les donjons / events RP Black Clover.

## Nouveautés

- Inscription **uniquement avec le nom RP**
- Suppression individuelle des inscrits
- Formation des groupes par **glisser-déposer** (drag & drop)
- Une personne dans un groupe n’apparaît plus dans « Non assignés »
- Maximum 12 par groupe / 24 au total

## Lancer le site

1. Ouvre un terminal dans le dossier du site
2. Lance :

```bash
python server.py
```

3. Ouvre ton navigateur :
   - Site public : http://localhost:8765
   - Admin      : http://localhost:8765/admin

## Comment former les groupes (Admin)

1. Connecte-toi
2. En bas de page tu as 3 zones :
   - **Non assignés**
   - **Groupe 1**
   - **Groupe 2**
3. **Glisse** les noms d’une zone à l’autre avec la souris
4. Clique sur **« Sauvegarder les groupes »**

Tu peux aussi supprimer un inscrit un par un avec la croix ✕.
